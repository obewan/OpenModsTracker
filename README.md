# Open Mods Tracker
An opensource mods tracker.

## Requirements
To use it you will need an user apikey from https://next.nexusmods.com/settings/api-keys (at the bottom of the list, under *Personal API Key*) 
as the software will made some calls to the [Nexus API](https://app.swaggerhub.com/apis-docs/NexusMods/nexus-mods_public_api_params_in_form_data/1.0).

This is a Windows Desktop App using WinUI3, so it will be better to use it under Windows 11.
